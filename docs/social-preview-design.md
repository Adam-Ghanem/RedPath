# Social preview design notes

The social card uses the **canonical repository red-fang asset** directly rather than an AI-rendered approximation. Its final visual hierarchy is intentionally simple: the red-fang mark on a dark forensic evidence-board field, the `RedPath` name, the tagline `See the path. Prove the gap.`, and a concise SOC-focused supporting line.

This preserves the project’s established brand identity while keeping the preview legible in GitHub link cards.
